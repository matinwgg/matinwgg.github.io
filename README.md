# Matin Odoom — Software Engineering & Research Portfolio

## 📖 About

Personal portfolio for **A. Matin Odoom**, a Ghanaian computer scientist and software engineer interested in secure backend systems, FinTech, applied cryptography, machine-learning security, distributed systems, and reliable software engineering.

The site brings together software projects, research-oriented work, technical experiments, academic material, and professional background.

## ✨ Portfolio Areas

- Software engineering and backend systems
- FinTech and financial-data systems
- Applied cryptography and security engineering
- Machine-learning security and trustworthy AI
- Distributed systems and reliable software
- Mathematics for computer science and AI
- Research projects and technical experiments

## 🛠 Technologies Represented

The portfolio spans technologies including Python, Rust, JavaScript/TypeScript, React, React Native/Expo, Django, FastAPI, Node.js, PostgreSQL, Redis, Docker, machine-learning tooling, and cryptographic libraries.
